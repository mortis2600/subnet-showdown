# Subnet Showdown

An open-source subnet calculator game.

Play subnet quizzes, use the full subnet calculator, study with flashcards, stories, and drills, and read the field guide.

- Client-side only, no server, no accounts, no uploads.
- Score is kept in the current browser tab only, not persisted.
- Open index.html in a browser, or visit the GitHub Pages site for this repo.
